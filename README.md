# 店舗問い合わせ AIアシスタント（操作デモ）

Microsoft 365（Teams・SharePoint・Outlook）上に、Copilot Studio と Power Automate で構築する
「店舗からの問い合わせに、社内規程・マニュアルを根拠に答える AI アシスタント」の操作デモです。

- 規程・マニュアルを根拠にした回答（出典表示）
- 店舗／本社で回答範囲を分ける権限制御
- 質問と回答のログ（SharePoint リスト）
- 回答の評価と、「解決しない」場合の本部共通メールへの通知
- 本部の回答を FAQ に登録し、次から AI が回答

表示データ（規程の内容・店舗名・氏名）はすべて架空のサンプルです。
